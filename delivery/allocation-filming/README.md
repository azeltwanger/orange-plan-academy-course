## Use the package

Open `Allocation_Rehearsal.html` for each slide beside its exact narration. Lesson navigation, Previous/Next, arrow keys, Hide narration and Slides only are available. Escape returns from Slides only. This is an instructor rehearsal aid, not an added student app or assignment.

In PowerPoint Presenter View, speak the `READ ALOUD` block only. The production block identifies the source paragraphs, visual notes and any app handoff. Each canonical read-aloud paragraph is included once and in order across its lesson. No teaching script was rewritten for this package.

The simple figures reveal the reasoning in stages. Full qualifications remain in the aligned narration rather than being removed to shorten the visible slides. Numbers from a separate example never become Reed facts or app outputs.

Members learn the decision, see the demonstration and apply it directly to their own plan. There is no practice portfolio, answer check, quiz, submitted explanation, required post or instruction to trade simply to finish. The existing phrase "write down" in narration does not create a second worksheet or required submission; carry the actual choice into the relevant plan step.

The visible design uses a dark background, restrained orange, native editable text/shapes and simple comparisons. The slides reference Inter without embedding or distributing font files. The PDFs preserve the reviewed appearance; font substitution in an editable deck should be checked before recording on another computer.
