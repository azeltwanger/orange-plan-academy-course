## Teach-to-walkthrough rule

The phrase `PUT IT IN ORANGE PLAN` is not a license to repeat the walkthrough.

When implementation belongs in the walkthrough, the teach script should close with a short handoff such as:

> In the walkthrough below this lesson, I'll show you exactly where to enter this, what the app calculates, and how to make sure it saved correctly.

Only the walkthrough should contain the full click path.
