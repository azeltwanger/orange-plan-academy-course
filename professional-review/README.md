# Professional review

This directory separates three things that must not be confused:

1. **Authoritative-source verification** — completed internally against current primary authorities.
2. **External professional review** — incomplete until an actual qualified reviewer returns a claim-level response.
3. **Austin voice approval** — happens after accepted factual corrections are applied.

**Actual outside sign-off is not complete.**

## Reviewer response codes

- `OK`
- `QUALIFY`
- `CHANGE`
- `CURRENT FACT`
- `PROFESSIONAL ONLY`
- `REMOVE`

The custody packet also permits `DEVICE/PROVIDER SPECIFIC`, `UNSAFE`, and `ADVANCED ONLY`. The insurance packet permits `STATE/CARRIER/CONTRACT SPECIFIC`.

## Clearance rule

A source pass is not professional sign-off. A high-stakes lesson remains held until:

1. the applicable reviewer returns the packet by claim ID,
2. accepted corrections are applied to script and lesson text,
3. changing facts are moved to maintained reference when appropriate,
4. all audits pass,
5. and Austin completes the final spoken read.

A generic “looks good” response without claim-level review does not clear the gate.
