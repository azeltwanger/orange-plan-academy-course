## Clearance rule

A public source, provider explanation, or generic “looks good” does not clear a lesson. The reviewer must address the claim IDs in scope. Accepted changes are applied to both script and lesson text, changing facts move to maintained reference, audits pass, and Austin completes the final clean read.

No reviewer receives customer data, Austin's personal plan, repository credentials, wallet addresses, account credentials, or Bitcoin secrets.
