## Before sending

- [ ] Current credential/license and relevant experience verified
- [ ] Conflicts and compensation disclosed
- [ ] Fee, scope, and due date agreed
- [ ] Claim-level response codes required
- [ ] Current packet version attached
- [ ] No repository write access or sensitive data granted
- [ ] Tracker updated

## After return

1. Log every response by claim ID.
2. Apply the minimum correction to script and lesson text.
3. Move changing facts to maintained reference.
4. Rerun all audits.
5. Clear only the reviewer's actual scope.
6. Give Austin the corrected lesson for one clean final read.

A generic approval without claim-level responses does not clear a gate.
