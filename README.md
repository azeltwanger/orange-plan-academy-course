## Walkthrough rule

Concept videos teach the durable financial-planning decision. Walkthroughs are replaceable, versioned, and track the accepted Build Your Plan implementation only after the deployed flow is verified.

Every walkthrough must:

1. Recall the decision.
2. Enter through the relevant Build Your Plan area.
3. Continue the same demo checkpoint.
4. Name whether the learner is viewing a saved input, preview, or Scenario.
5. Implement only the decision the lesson taught.
6. Explain the important result using **What it means · Calculated from · Edit source · This affects**.
7. Return to Build Your Plan.
8. Distinguish the app completion rule from the human planning finish line.

## Professional-review rule

Primary-source research is complete. Actual outside sign-off is not.

A high-stakes lesson is not called professionally reviewed until the applicable reviewer returns the claim-level packet, accepted corrections are applied to script and lesson text, audits pass, and Austin completes the final spoken read.

## Current encrypted-export limitation

Orange Plan can create a passphrase-protected encrypted export for secure storage and portability. **In-app plan restore is currently unavailable.** Course materials must not describe that export as a restore the learner can use today. The active plan and source records remain necessary until a restore process is exposed and reverified.

## Before filming

A lesson is film-ready only after:

- demo inputs and app-calculated outputs match the accepted receipt,
- visible app terminology and saved/preview/Scenario behavior match the accepted build,
- required professional corrections are applied,
- Austin approves the planning judgment and spoken wording,
- matching lesson text agrees,
- one primary visual supports the same concept,
- and the walkthrough is verified against the deployed Build Your Plan flow.
