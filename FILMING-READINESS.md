## Meaning of the demo statuses

- `INPUTS LOCKED` — the fictional source value is proposed in `DEMO-HOUSEHOLD.md`; Austin approval still required.
- `OUTPUTS HOLD` — the number must come from a current app run and cannot be made canonical from script arithmetic alone.
- `REAL-WORLD TEST HOLD` — the app can record completion, but a device, family, provider, or legal process supplies the proof.
- `POLICY DATA TBD` — policy terms are intentionally not invented for the fictional household.
- `CHECKPOINT HOLD` — requires the saved demo account after prior modules are complete.
- `MAPPED` — the current visual has a keep/edit/replace/move/remove decision in `research/SLIDE-CORRECTION-MAP.md`; the revised slide itself is not built yet.

## Film-ready checklist for one lesson

A lesson becomes film-ready only when:

- [ ] The main decision is one sentence.
- [ ] Demo values reconcile with `DEMO-HOUSEHOLD.md`.
- [ ] Any calculated output comes from the current checkpoint or is explicitly illustrative.
- [ ] Duplicate teaching has been cut.
- [ ] App terminology and behavior were checked against current `main` or the accepted preview.
- [ ] Changing facts live in lesson text or a maintained reference rather than being casually hardcoded in evergreen video.
- [ ] Required professional reviewer cleared or corrected the claims.
- [ ] Austin approved the planning judgment and spoken wording.
- [ ] Matching lesson text reflects factual and structural changes.
- [ ] One primary visual supports the decision.
- [ ] The `YOU ARE DONE WHEN` result can be checked.
- [ ] No essential concept exists only in the future walkthrough.

## Austin review begins after these pre-dictation gates

1. Canonical demo inputs approved and entered
2. App-calculated demo outputs captured
3. Duplicate cuts applied and runtime measured
4. Professional reviewers have either responded or the affected wording is visibly held
5. Slide corrections affecting the spoken concept are known

At that point Austin should need a targeted judgment-and-voice pass, not a second structural rewrite.
