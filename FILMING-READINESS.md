# Orange Plan Academy — filming readiness

This file begins where `PRE-DICTATION-QA.md` ends. It tracks whether an Austin-approved lesson can actually be recorded and published.

## Status key

- `PASS` — complete for the accepted build
- `HOLD` — an external or product dependency remains
- `AUSTIN` — ready for Austin's final read
- `APPROVED` — Austin approved the final spoken wording
- `FILM` — concept video can be recorded
- `PUBLISH` — concept, text, visual, and walkthrough are synchronized

## Film-ready checklist for one concept lesson

- [ ] Main decision is one sentence.
- [ ] Demo input and app-calculated outputs match the accepted checkpoint.
- [ ] No calculated output is invented for continuity.
- [ ] App terminology and behavior match the accepted build.
- [ ] Changing-year facts live in maintained lesson text or reference material.
- [ ] Required professional reviewer cleared or corrected the claim.
- [ ] Austin approved the planning judgment and spoken wording.
- [ ] Matching lesson text includes the same facts and finish line.
- [ ] One primary visual makes the decision obvious.
- [ ] The `YOU ARE DONE WHEN` result can be checked.
- [ ] No essential concept exists only in the walkthrough.

## Walkthrough-ready checklist

- [ ] Austin has personally completed the deployed Build Your Plan preview.
- [ ] `app_step_id`, label, route, and completion rule are recorded.
- [ ] Demo checkpoint begins where the prior walkthrough ended.
- [ ] Save, preview, and Scenario state are named correctly.
- [ ] Every important output is traced to its source.
- [ ] App checkmark and human decision finish line are both stated.
- [ ] Recording date and verified app commit are stored with the run sheet.

## Module 9 export check

Before recording, confirm whether the app currently supports restore. At this writing, encrypted export is available and restore is temporarily unavailable. The video must describe the current state rather than a future capability.

## Publish-ready checklist

After concept and walkthrough approval:

1. Synchronize the approved script into any generated master or aggregate file.
2. Update the matching lesson text and current slide deck.
3. Record and attach the versioned walkthrough.
4. Update module checkpoints and Circle publishing files.
5. Archive the superseded script, walkthrough, deck, and generated copy.
6. Run the course audit and the app/course impact check.
