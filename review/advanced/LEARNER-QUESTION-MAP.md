# Austin review — Advanced learner-question map

Use this before reading each conditional script.

> **Gate → real learner question → worked example → Austin's judgment → one decision → return to Core**

| Lesson | Real learner question | Decision |
|---|---|---|
| A1.1 | What stays fixed, what changes across the 1,000 runs, and why should I trust the comparison? | Baseline model and one alternate assumption |
| A1.2 | Is this holding actually modeled by the correct return and income assumptions? | Documented overrides only where needed |
| A2.1 | How far can Bitcoin fall before this loan reaches the lender's action or liquidation line? | Whether to borrow and maximum starting LTV |
| A2.2 | What will I do at each LTV line, and do I really have enough BTC or cash? | Survival ladder, repayment, and exit |
| A2.3 | Should I sell Bitcoin or borrow against it for this same cash need? | Funding source based on full cost and risk |
| A2.4 | Is this lender structure acceptable, and how do I get out? | Provider and written exit rules |
| A3.1 | Can I prove my basis and sell the exact lot the plan modeled? | Reconstruction and identification owner |
| A3.2 | How much should I convert without creating a worse tax, cash, or healthcare result? | Conversion range and tax source |
| A3.3 | Is this gain or loss worth realizing now? | Lot, amount, exposure plan, or deliberate pass |
| A3.4 | Does moving still improve our life after every cost—not just state tax? | Real relocation Scenario and residency questions |
| A4.1 | Which accounts can actually fund each year before 59½? | Primary and backup source by year |
| A4.2 | What will healthcare really cost before Medicare, and how does income change it? | Coverage, full cost, MAGI range, and transition |
| A4.3 | Which withdrawal mix funds the lifestyle without breaking tax, healthcare, or the Bridge? | Annual funding range |
| A5.1 | Does a passphrase solve a real risk, and can my family recover it? | Keep simple or add/test the second component |
| A5.2 | Would collaborative or DIY multisig actually improve family recovery? | Custody design based on independent recovery |
| A5.3 | How do I move the Bitcoin without making the migration the biggest risk? | Staged migration and test plan |
| A6.1 | What exact problem would a trust solve for us? | Baseline documents versus professional trust comparison |
| A6.2 | Do the trust, provider records, tax file, and Bitcoin access plan agree? | Ownership/authority matrix and implementation owners |

Mark `GATE` when the lesson is too broad, `QUESTION` when it answers a different problem, and `ADVANCED ONLY` when execution should leave the Academy entirely.
