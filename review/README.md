## Teaching standard

Core:

> **Real learner question → worked example → Austin's judgment → one decision → checkable finish line**

Advanced:

> **Plan-visible gate → learner question → worked example → Austin's judgment → trade-off → one decision → return to Core**

## Review marks

- `APPROVE` — keep it
- `TIGHTEN` — right idea, too long
- `SAY IT THIS WAY` — dictate replacement wording
- `JUDGMENT` — recommendation or trade-off is not Austin's
- `QUESTION` — lesson answers the wrong learner question
- `GATE` — Advanced condition is too broad or too narrow
- `APP` — final app label/behavior needs verification
- `PRO` — outside professional must clear the claim
- `ADVANCED ONLY` — remove implementation from Core or send it fully to a professional/provider
- `REMOVE` — learner does not need it

A named hold blocks final approval and filming. It does not require Austin to postpone review of the stable concept prose.
