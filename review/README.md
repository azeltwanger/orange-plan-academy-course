## Review marks

- `APPROVE` — keep the section
- `TIGHTEN` — right idea, too long
- `SAY IT THIS WAY` — dictate replacement wording
- `JUDGMENT` — disagree with the recommendation or example
- `APP` — final app behavior or label must be verified
- `PRO` — external professional must clear the claim
- `REMOVE` — the learner does not need it
