# A4.2 · Four ways debt can strengthen a plan—and how each one fails

**Paste `00-STYLE.md` first, then this.**

## What it has to make obvious
Each debt play has a specific job, a condition that makes it useful, and a failure mode that can make the plan fragile.

## The visual
Four equal cards:

1. Keep low-rate debt and invest the capital
2. Borrow for liquidity instead of selling immediately
3. Use conservative Bitcoin-backed borrowing from a strong balance sheet
4. Establish optional access to credit before it is needed

Each card has three rows:

- **Job**
- **Works when**
- **Breaks when**

Give the failure row at least as much visual weight as the upside.

## Motion
Build each card from job to conditions to failure mode. End with the four failure rows visible together.
