# Walkthrough: model it in Orange Plan (tax)

<!-- PLAN-LIFECYCLE:LESSON-TEXT -->

Foundation recorded current ownership. This walkthrough reconstructs purchase history and cost basis for Tax.


Follow along (~20 minutes). Have last year's return and a wallet/exchange export ready. Run the import first, because harvest rooms only show for recorded lots.

1. **Import history**: Dashboard → Update Transactions → A downloaded file. The app never invents basis; flagged lots are your homework.
2. **Land on the lots**: Strategy → Tax → Tax lots. Get the coverage banner to "Tax-lot records reconcile." Fix wrong lots from the holding's **Lots** dialog (sold lots are locked on purpose; unwind in order; "quantity exceeds holding" = a double import to delete).
3. **Ground the three buckets**: Plan → Retirement → year drawer → Account mix. Levers need a mix.
4. **Model a Roth conversion**: Strategy → Tax → Moves this year → Roth conversion. Compare strategies, customize the schedule, set Tax funding to **Plan cash flow** (pays the tax from outside the Roth), apply, and watch "Projected year-end traditional" shrink.
5. **Harvest room + Form 8949**: read "$X more at 0%," filter the lots, **Export 8949** for your CPA.
6. **State scenario**: Scenarios → See more → Move to no-tax state. Residency is a legal standard, not an address.
7. **AI review**: Review Tax Strategy; answer its question about untracked tax events honestly.
8. **Capture decisions**: this year's moves, next low-income-year moves, and exact CPA questions. On top: "Am I leaving low brackets empty?"

**Done when:** banner reconciles, the bracket is filled not spilled, the RMD balance visibly shrinks, the 8949 file is on disk, and the state swing is framed against the life trade-off.
