# Walkthrough: document your custody map

Follow along (~15 minutes). The app's checklist tier keys to estate net worth (Foundation <$500k / Substantial $500k–$2M / HNW $2M+); Hardware items appear at Substantial+. If you'll arm the dead-man switch next module, flip to Cloud mode now.

1. **Orient on Protect** — the readiness bar ({n} of 5 essentials) and the Needs attention queue: always the next single fix.
2. **Walk the checklist honestly** — 4 groups (Hardware / Distribution / Legal / Access after death). Check "recovery tested" and "backup verified" only if you actually did them — a checked box that never happened means the plan believes something untrue. The top unchecked item is this week's fix, not the whole list. No free-text anywhere: never write secrets in the app.
3. **Back up the plan itself** — Settings → Data & Privacy → Data & backups → Export Plan. The passphrase prompt is for the *backup file*, not a wallet. In Local Only mode this file is your only backup.
4. **Fill the Family Custody Map** (toolkit PDF, Materials → 07) — one sheet: Bitcoin rows, where backups are (**location only, never the words**), accounts, insurance, documents. Store with the will and Heir Letter. The letter says who to call; the map says what exists and where.
5. **Record decisions** — custody level chosen, top single point of failure + this week's fix, annual custody review on the calendar.
6. **Walk past "Draft with AI"** — that's the heir letter assistant, next module's job.

**Done when:** Needs attention is shorter than at the start, the hardware items are honest, no secret was typed anywhere, and the encrypted plan file is on disk.
