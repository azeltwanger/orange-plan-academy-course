# Set up a hardware wallet and prove the backup works

Follow the current manufacturer instructions for the exact device and backup format.

## The standard

A complete hardware-wallet setup includes:

- Verified device and official software
- New wallet generated by the device
- Offline wallet backup
- PIN or local device protection
- Receiving address verified on the hardware-wallet display
- Small receive and send test
- Manufacturer-supported backup or recovery test
- Backup locations that survive loss of the device and one physical event

## Never accept a supplied backup

A new device should not arrive with prewritten words or an already-created wallet. Stop when the packaging, firmware, or setup does not match official instructions.

## Keep the backup offline

Never photograph, upload, email, or type the wallet backup into a computer, phone, password manager, cloud note, support chat, or AI tool.

Different wallets use different standards. Confirm compatibility before restoring to another device or application.

## Verify on the trusted display

Before receiving, compare the address shown on the hardware wallet with the sending app.

Before sending, verify the destination, amount, and fee on the hardware-wallet screen before approval.

Reject any mismatch.

## Test recovery safely

Use the manufacturer's supported backup check, a compatible spare device, or another documented recovery drill.

Do not wipe the only working device holding meaningful funds unless the backup has already been verified, the process is understood, and a safe fallback exists.

A recovered wallet must reproduce the expected accounts and addresses. A passphrase, when used, must also be tested because it may open a different wallet.

## Family practice

Use a small practice wallet so a spouse, executor, or trusted helper can learn the sequence without exposing the main backup or risking the primary balance.

## App versus real completion

Protect records device and recovery status. The real custody process supplies the evidence; Orange Plan never receives the secret.

## Done when

A small receive and send work, details were verified on the device, recovery succeeded, and required family participants know where the process begins.
