# How these files work

- **This Drive folder is the source of truth** for course scripts and production docs. The Honen draft mirrors it; the orange-plan repo never contains course files (Austin's rule).
- `01`–`11` are the eleven modules — every lesson, verified against the Honen draft and the live app code (last full verification sweep: 2026-07-31).
- `FILMING-CHECKLIST` is the production plan. `COURSE-IMPROVEMENT-ANALYSIS` is the decision log (32 tracked items and counting).
- Lines starting with `>` and `⚠` are production notes for Austin/Claude — they are never read on camera and never shown to students.
- **To work on the course in a Claude session:** say "pull the course from Drive" — Claude reads these files, makes the edits here AND in the Honen draft, and re-uploads so the two never drift.
