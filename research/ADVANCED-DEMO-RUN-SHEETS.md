# Orange Plan Academy — Advanced demonstration run sheets

**Rule:** a demonstration implements an already-taught decision. It never introduces the first useful example and never exposes a real secret, customer record or unredacted sensitive agreement.

## Standard receipt

Every recording stores:

```yaml
advanced_demo_id:
lesson_ids:

recording_date:

important_output_keys:
external_proof_required:
return_to_core:
```

## AD1 · Inspect assumptions and holding overrides

**Lessons:** A1.1–A1.2  
**Format:** Orange Plan screen-share  
**Starting state:** approved demo Baseline  
**Decision:** keep built-in Power Law/3% Baseline, compare 4% inflation, verify one spot Bitcoin ETF follows Bitcoin assumptions

Sequence:

1. Show current Plan assumptions and model/version help.
2. Record the Baseline confidence result.
3. Open the 4% inflation Scenario and show only the changed input.
4. Reconcile the confidence difference.
5. Open a synthetic spot Bitcoin ETF holding.
6. Show broad classification, advanced return source and income/yield distinction.
7. Save only the classification correction; leave a speculative custom rate unsaved.
8. Return to Baseline and Allocation.

**Hold:** exact labels, save state and model receipt.

## AD2 · Model a Bitcoin-backed loan and drawdown

**Lessons:** A2.1–A2.3  
**Format:** Orange Plan screen-share using fictional terms  
**Synthetic terms:** $30,000 loan, 1.50 BTC collateral, $100,000 BTC, 65% action, 80% liquidation

Sequence:

1. Confirm Core sell/no-loan Baseline.
2. Add the synthetic loan comparison without applying it.
3. Reconcile 20% starting LTV and threshold prices.
4. Run the price path and show collateral at lender.
5. Add finite top-up/paydown resources and show one resource being consumed.
6. Compare the same $30,000 cash need under sale and loan.
7. Read tax difference, interest, BTC retained, drawdown behavior, later/death balance and net result.
8. Mark the loan tax treatment provisional.
9. Leave the loan as a preview/Scenario unless the fictional household deliberately applies it.

**Hold:** deployed borrowing UI and CPA/lending review.

## AD3 · Read a lender agreement and write the exit

**Lesson:** A2.4  
**Format:** redacted synthetic agreement walkthrough

Highlight:

- legal/control structure,
- segregation and permitted reuse,
- price source/frequency,
- action and liquidation thresholds,
- notice/cure,
- partial/full liquidation and fees,
- top-up/release,
- rate/reset/renewal,
- repayment/prepayment,
- incapacity/death,
- governing law and dispute process.

End with a one-page action ladder and exit rule. Do not recommend a lender.

**Hold:** lending/legal claim response.

## AD4 · Reconstruct lots and prepare a sale packet

**Lesson:** A3.1  
**Format:** synthetic transaction worksheet + Tax Center

Sequence:

1. Reconcile current 1.75 BTC.
2. Show 1.25 complete, 0.40 reconstruction, 0.10 unresolved.
3. Match transfers without creating purchases/sales.
4. Show current planning lot comparison.
5. Build the sale packet: wallet/account, quantity, lot, basis, selection record, transaction ID placeholder, proceeds/fees and CPA handoff.
6. Leave unresolved units visibly unresolved.

**Hold:** CPA and current provider/wallet identification procedure.

## AD5 · Compare conversion, harvest and relocation Scenarios

**Lessons:** A3.2–A3.4  
**Format:** Orange Plan + maintained tax worksheet

Record three separate comparisons:

1. No conversion / smaller conversion / first-pass ceiling
2. No harvest / smaller harvest / proposed harvest
3. Current state / genuine move Scenario including housing, work, spending, property and tax

For each, show one primary decision, cash source, downstream outputs and professional question. Do not combine all three into one “optimized” Scenario.

**Hold:** CPA/state review and current Tax Center labels.

## AD6 · Build the pre-59½ and healthcare Bridge

**Lessons:** A4.1–A4.3  
**Format:** Orange Plan + synthetic plan documents/quote worksheet

Sequence:

1. Start from one full pre-Medicare year's total draw.
2. Map primary and backup source by year.
3. Add only documented employer-plan access, Roth basis and qualified HSA amounts.
4. Show why tax and additional tax are separate.
5. Enter a current/synthetic all-in healthcare cost with start/end dates.
6. Compare the same $100,000 spendable cash under taxable, conversion and employer-plan mixes.
7. Read tax, net premium, Bridge used and future balances.
8. Save an annual range, not a rigid decade-long order.

**Hold:** plan documents, current quotes, CPA/healthcare/Medicare review.

## AD7 · Passphrase practice wallet

**Lesson:** A5.1  
**Format:** device-specific practice wallet with a trivial balance

Prove:

1. backup-only wallet,
2. exact passphrase wallet,
3. small receive and send,
4. recovery on a clean/compatible device,
5. family process without exposing the actual passphrase.

Never record the mnemonic, passphrase, PIN, xprv, QR containing secret material or full recovery path.

**Hold:** exact device/manufacturer process and custody review.

## AD8 · Compare and recover a 2-of-3 wallet

**Lessons:** A5.2–A5.3  
**Format:** provider-neutral or redacted collaborative practice setup

Sequence:

1. State the three-key/two-sign threshold.
2. Show process-level failure domains and protected configuration copies.
3. Prove intended signing combination.
4. Remove one key and prove alternate authorized combination.
5. Prove one key alone cannot spend.
6. Reconstruct from backups/configuration in compatible software.
7. Compare provider-assisted and provider-independent recovery.
8. Complete practice wallet → small live tranche → destination spend → staged migration → family practice.

**Hold:** specific provider/device/coordinator and estate/custody review.

## AD9 · Trust ownership and authority matrix

**Lessons:** A6.1–A6.2  
**Format:** no-secrets worksheet walkthrough

Use the demo mismatch:

- trust says it owns 1.50 BTC,
- wallet still belongs to Alex,
- Jordan is successor trustee,
- only Alex knows recovery.

Build one row per asset with legal owner, intended owner, beneficiary/provider record, authority during life, authority after death, technical access, tax/basis record, proof and implementation owner.

Show that signing the trust does not update the wallet, retirement account or provider. End with unresolved actions assigned to attorney, CPA, provider and custody practitioner.

**Hold:** Colorado attorney/CPA/custody responses and provider acceptance.

## Recording prohibition

Never display or request:

- seed phrase,
- private key,
- passphrase,
- PIN/password/authentication code,
- xprv,
- real account number,
- real client record,
- unredacted lender agreement,
- or a complete map that independently enables spending.
