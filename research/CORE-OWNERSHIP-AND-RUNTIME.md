# Core lesson ownership and runtime

**Status:** pre-dictation editing contract  
**Goal:** make the core thorough enough to build a real financial plan without forcing the learner to hear the same explanation in the script, slide, lesson text, and later module.

## Runtime target

The current script headers imply roughly **4 hours 45 minutes of core concept video** before walkthroughs.

The target after the trim is **about 3 hours 35 minutes to 3 hours 50 minutes** across the same 28 core teach lessons.

This is not achieved by speaking faster or cutting necessary explanations. It is achieved by:

- giving each lesson one primary decision,
- keeping one full explanation of each difficult concept,
- turning later repeats into short callbacks,
- moving changing numbers and long checklists into lesson text,
- moving edge-case implementation into Advanced,
- and letting the visual carry tables that do not need to be read aloud.

Most core lessons should land around **6–9 minutes**. A 10-minute lesson is fine when the worked example earns it. A script should not remain 11–12 minutes because it contains three neighboring lessons.

## Ownership rules

1. **One concept has one home.** Later lessons may recall it in one or two sentences.
2. **One lesson ends with one primary decision.** Supporting checks may exist, but they should lead to the same decision.
3. **The spoken lesson owns reasoning.** The lesson text owns changing rules, tables, checklists, and source detail.
4. **The visual owns comparisons.** Do not read every row of a table on camera.
5. **The walkthrough owns implementation.** Concept scripts name the durable app area and output, not every temporary button.
6. **Advanced owns edge cases.** A core gate can explain why the edge case matters and who should watch it.

# Core-to-Advanced moves

The following material should remain discoverable but should not consume the main core explanation:

- Monte Carlo sampler mechanics and model construction
- Detailed custom return periods
- Bitcoin-backed-loan capacity, lender mechanics, refinance, liquidation, and estate payoff
- Detailed Roth-conversion sizing, harvesting, and relocation analysis
- Contribution limits and changing tax thresholds
- Self-directed retirement Bitcoin and prohibited-transaction implementation
- Rule of 55, 72(t), Roth-basis, and other early-access implementation
- Passphrase design
- Collaborative and DIY multisig setup
- UTXO management and coin control
- Trust selection, estate tax, special-needs, and business succession
- Long-term-care product comparison

The core can name the gate, explain the risk, and tell the learner what plan condition makes the advanced lesson relevant.

# Editing sequence

1. Apply the demo-number patches.
2. Trim each script to the ownership contract above.
3. Update the matching lesson text to hold the material removed from speech.
4. Recalculate runtime from final word counts.
5. Verify that no lesson loses the reason behind Austin's recommendation.
6. Mark duplication/runtime `PASS` in `PRE-DICTATION-QA.md` only after the full cross-script read.

This pass is complete when later lessons feel like the same plan becoming more complete, not the same course restarting from the beginning.
