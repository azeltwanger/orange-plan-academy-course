# Core runtime and duplication audit

**Status:** pre-dictation audit — edit application pending  
**Scope:** 28 core teach scripts; walkthroughs and Advanced Library excluded

## Goal

Before Austin reads the scripts aloud, remove repeated teaching and make sure each lesson owns one decision.

The objective is not to make every video short. It is to remove time that does not improve understanding, a decision, number provenance, or avoidance of a consequential mistake.

## Runtime standard

A core lesson earns its place when it contains:

1. One main decision
2. One primary worked example
3. One app connection
4. One number-provenance explanation when applicable
5. One checkable `YOU ARE DONE WHEN`

A section moves out of spoken video when it is useful only as:

- a changing reference number,
- a detailed edge case,
- a professional implementation rule,
- a product click path,
- or a repeat of an earlier lesson.

The exact word-count and runtime measurement should be run after the edits below are applied. Initial target: remove roughly **15–25% of repeated spoken material**, not 15–25% of the financial-planning substance.

## Acceptance test

A script passes the duplication review when:

- its main decision can be stated in one sentence,
- no adjacent lesson owns the same explanation,
- earlier concepts are recalled rather than retaught,
- the demo changes only one main lever,
- the app connection is durable rather than a click tour,
- the professional implementation detail is properly gated,
- and cutting the section would remove understanding rather than only words.
