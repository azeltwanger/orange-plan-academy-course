# Core curriculum perfection audit

**Status:** pre-dictation edit plan  
**Scope:** module outline, 28 core teach scripts, and matching lesson text  
**Not in scope yet:** walkthrough click paths, Build Your Plan preview capture, Circle publishing, or the full Advanced Library

The core sequence is sound. The remaining curriculum work is to make each lesson own one decision, remove repeated teaching, reconcile the continuous demo household, and get the concept runtime below four hours before Austin performs the final voice review.

## 1. Course-level judgment

### Keep the current core sequence

`Start Here → Baseline → Cash Flow → Debt → Allocation → Tax → Retirement Income → Custody → Estate → Maintain / Test / Report`

Debt remains before Allocation in the teaching sequence because the learner should decide which debts deserve extra money before deciding where the flexible next dollar goes. The future walkthrough can still enter the matching Build Your Plan area in the app.

### Keep Core and Advanced separate

Core contains the decisions required for a usable plan. Advanced is conditionally linked from the planning area that makes it relevant.

Do not make these required merely because the app supports them:

- Bitcoin-backed borrowing
- Detailed Monte Carlo mechanics
- Custom holding return periods beyond the necessary override note
- Roth conversion optimization
- Tax harvesting and relocation
- Pre-Medicare healthcare optimization
- Passphrases and DIY multisig
- Trust and estate-tax design

### Target runtime

The current draft headers imply roughly **4 hours 45 minutes** of core concept teaching before walkthroughs. The target is approximately **3 hours 50 minutes**, without removing any planning decision.

The reduction comes from removing repeated explanations, not speaking faster or turning the scripts into outlines.

## 4. Repetition rules for the actual script edit

### Keep useful repetition

Repeat when the learner must apply an earlier concept in a new calculation.

Examples:

- “Debt payments are separate because they end” when retirement spending is reconciled.
- “Fix the source, not the output” when a Scenario or report number looks wrong.
- “No secret goes in the document” at the exact moment the learner creates a custody or estate document.

### Cut duplicated teaching

Do not repeat:

- the full 1,000-test-run explanation after 1.3,
- the full normal-vs-bare-bones explanation after 2.1,
- the full reserve range after 2.2,
- the full Roth/traditional lesson in Allocation,
- detailed borrowing mechanics in Core,
- the entire custody-level framework in each protection lesson,
- or every prior module during the annual-review lesson.

### Number provenance should sound natural

The lesson text may use all four headings:

- What it means
- Calculated from
- Edit source
- This affects

The spoken script should usually explain the same chain in 20–40 seconds rather than reading four identical labels every time.

## 5. Progression checks

Before Austin reviews a script, confirm:

1. Every term was taught before it is used.
2. The lesson asks for one main decision.
3. The continuous demo starts from the prior checkpoint.
4. No use of cash exceeds the available source.
5. App mechanics and Austin’s judgment are distinguishable.
6. A calculated output is never described as a field the learner types.
7. The close says what the learner decides, where it eventually goes, and how completion is recognized.
8. Optional content is visibly optional before the learner spends time on it.
