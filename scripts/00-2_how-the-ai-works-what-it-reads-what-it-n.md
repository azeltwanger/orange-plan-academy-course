Orange Plan AI is an explanation layer for the financial plan. It is not a second calculator sitting beside it.

== THE APP CALCULATES; THE AI EXPLAINS ==

The planning engine calculates surplus, reserve target, debt ratios, tax estimates, confidence, retirement spending, withdrawals, and the other plan outputs.

The AI reads the relevant plan result and can help explain:

- what a number means,
- why it moved,
- which input produced it,
- which options exist,
- and what question belongs with a professional.

If Cash Flow shows $2,400 of monthly surplus, the AI did not invent that number. The app calculated it from income, estimated tax, living spending, and debt payments.

The AI can trace the result. It should not replace the plan with its own arithmetic.

== ASK FROM THE AREA THAT OWNS THE DECISION ==

A Cash Flow question needs different context from a tax or custody question.

Use the review from the planning area where the decision lives when that feature is available.

A useful answer points to the number the page shows and the source that can be checked. When information is missing, the answer should identify the missing input rather than quietly filling it in.

The explanation is only as useful as the data beneath it. If the AI says spending is $90,000, verify the saved spending input or transaction summary that produced it.

== NEVER GIVE IT A SECRET ==

Never enter a seed phrase, private key, passphrase, PIN, password, wallet backup, full account number, Social Security number, or one-time authentication code into any AI tool.

The AI does not need a Bitcoin secret to review a custody process. It can know recovery is incomplete without receiving the backup. It can know an account exists without receiving the login.

If a seed phrase or private key has already been entered into a website, AI chat, photo, cloud note, or other connected system, treat it as exposed and use a verified new-wallet migration process.

== IT CAN SHOW A TRADE-OFF; YOU MAKE THE DECISION ==

The AI can explain that:

- extra debt payments reduce interest and leave less to invest,
- a higher confidence target generally moves the earliest date later,
- or borrowing may retain more Bitcoin while adding interest, LTV, liquidation, and counterparty risk.

It does not know how much debt makes the household lose sleep, how the spouse feels during a drawdown, or how much custody complexity the family can operate.

The app shows the effect. The AI explains the effect. The household makes the decision.

For tax, legal, insurance, custody-provider, or lending rules that can change or depend on the situation, use AI to understand the mechanism and prepare the question. Verify the current rule and final action with the appropriate professional.

== MEMORY IS OPTIONAL ==

When Orange Plan offers an optional memory setting, useful memory is planning context:

- preference to avoid selling Bitcoin,
- becoming work-optional before maximizing spending,
- or discomfort with carrying debt.

It is not a place for balances, credentials, account numbers, recovery information, or secrets.

Turn it on only when the convenience is useful and the setting is one you are comfortable using. Leaving it off does not stop the planning engine from calculating the plan.

== CHECK AN AI ANSWER ==

Use three checks:

1. Does the answer point to a number the app actually shows?
2. Can that number be traced to the source input?
3. Did the answer explain the trade-off and leave the decision with you?

If it invents a fact, contradicts the page, or tells you to act without the trade-off, fix the data, ask a narrower question, or verify the claim elsewhere.

== YOUR DECISION ==

Choose whether optional memory is on or off and use the AI as an explanation layer rather than the source of the plan.

== PUT IT IN ORANGE PLAN ==

Open AI Review, inspect the available privacy and memory settings, and make the choice deliberately.

== YOU ARE DONE WHEN ==

You can explain the difference between the planning engine and AI, and you can state the rule from memory: no Bitcoin secret or account credential goes into an AI tool.
