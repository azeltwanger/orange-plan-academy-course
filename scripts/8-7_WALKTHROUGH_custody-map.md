# 8.7 · WALKTHROUGH — Document your custody map

**Screen capture · 6 steps · ~15 min**

> **DO** = click path · **SEE** = point at this · **⚠** = don't get this wrong
> Narrate in your own words. Nothing here is scripted.

---

## Before you record

- [ ] Custody level from 8.2 in mind · know whether the dead-man switch will need cloud sync
- [ ] **Tier is keyed to ESTATE NET WORTH, not custody choice:** Foundation <$500k · Substantial $500k–$2M · HNW $2M+. The 3 Hardware items only exist at Substantial+
- [ ] **Local Only mode** replaces the switch panel with *"Automatic check-in emails require cloud sync."* Flip to Cloud at Settings → Data & Privacy now if you're arming next module
- [ ] Zero secrets on screen. The checklist never asks for any — the ONLY free-text moment in the whole walkthrough is the backup passphrase in step 3

## □ 1 · Orient on Protect

**DO** Protect (primary nav)

**SEE** Top strip: **Estate readiness → {n} of 5 essentials** · five segments: Dead man's switch · Heir letter · Protection tier · Checklist · Beneficiaries

**SEE** Below it: **"Next: {action} · start →"** — the app naming the next single fix

**SEE** **Needs attention** queue — one row per essential. That's the fix-one-thing method.

**⚠** Two different "checklist" strings exist: the readiness bar says **Checklist**, the queue row says **Security checklist**. Both are real.

---

## □ 2 · Walk the checklist as the map

**DO** Needs attention → Security checklist → **Open checklist**

**SEE** Panel: *"{n} of {n} for your tier · Substantial ($500K–$2M) · Items name outcomes; any custody model can satisfy them"*

**SEE** Four groups (17 items at Substantial): **Hardware** (3, Substantial+ only) · **Distribution** (4) · **Legal** (6) · **Access after death** (4)

**SEE** Each item has a **How** toggle · checked items strike through

**⚠** The top unchecked item is this week's fix. Not the whole list.

**⚠ The honesty beats, verbatim from the app:** *"Full recovery process tested end-to-end"* and *"Backup seed verified readable."* Check these ONLY if the wipe-and-restore actually happened. Checked-but-fabricated means the plan believes something untrue.

**SEE** The single-point-of-failure beats: *"Storage locations documented. Hints only"* · *"No single point of failure can destroy access"*

**⚠** There are no free-text fields anywhere here — checkboxes and How toggles only. Never write secrets into the app.

---

## □ 3 · Back up the plan itself

**DO** Settings → Data & Privacy → **Data & backups** → Backup & Restore → **Export Plan**

**⚠** The click target is the ROW *"Data & backups."* "Backup & Restore" is the panel heading after it expands — there's no top-level tab.

**SEE** Copy: *"Export your entire plan as an AES-encrypted restore backup file protected by a passphrase"*

**⚠** It opens a PLAINTEXT browser prompt. Type it off-camera, or use a visible throwaway.

**⚠** Say it: this is a backup passphrase, NOT a wallet passphrase. Two objects, two jobs.

**SEE** Toast **Plan exported** · the sibling Data Privacy panel shows Cloud / Local Only

**⚠** Land the line: the rest of the module protected the coins. This button protects the map.

---

## □ 4 · Save the Family Custody Map (course toolkit PDF)

**DO** Materials → **07 Family Custody Map** — print it or fill it as a PDF, store with the will + Heir Letter

**DO** Fill the five blocks as you talk:
- **BITCOIN** — one row per instance, provider named
- **WHERE THE BACKUPS ARE** — location ONLY ("steel backup: safe deposit box, First National"), never the words
- **ACCOUNTS** — beneficiary forms current
- **INSURANCE & OTHER**
- **DOCUMENTS** — original + who has copies

**⚠** This map never contains a secret. It says WHERE things are, never HOW to open them. The footer says it too: never the words, PIN, or passphrase.

**⚠** The companion framing: the letter is who to call in what order, the map is what exists and where. Both have to be findable by the executor.

**DO** Set the footer review date

**⚠** Review it yearly. That lands in Module 9.
