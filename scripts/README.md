# scripts/ — what's here and how to film from it

One file per thing Austin says on camera, sorted in filming order by filename.

| Filename pattern | What it is | How it's filmed |
|---|---|---|
| `3-2_...` | Teach lesson script | Teleprompter, camera on Austin |
| `3-4_WALKTHROUGH_...` | Walkthrough narration script | Screen recording; read while clicking (app state prep in SCREEN-SHOOT-LIST.md) |
| `5-1-A_...` + `5-1-B_WALKTHROUGH_...` | Hybrid lesson: teach half + app half | Film separately, published as lesson video + walkthrough video below it |

Rules every script follows: `VOICE-GUIDE.md` (calibration master =
Austin's own dictated 3-2). Openers are one line ("In today's lesson,
we're going to..."), no tables, no law-set numbers, teach scripts end by
handing off to "the walkthrough below this video."

Review order before filming = file order. The per-module two-sitting plan
(all teach scripts, then all walkthroughs) is in FILM-ORDER.md.
