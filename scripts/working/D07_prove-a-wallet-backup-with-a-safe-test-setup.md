### Run sheet

**Required receipt before filming:** manufacturer/model, firmware, wallet software, backup standard, official procedure URL/date, small test amount, and independent security review. This is not permission to improvise a universal reset procedure.

1. Verify source/authenticity using the manufacturer's current process. Show no existing funded household wallet.
2. Create a new test-only wallet; cut or mask all secret-generation footage. Never publish a usable seed even for a purportedly disposable wallet.
3. Explain PIN versus recovery backup versus any passphrase. Retain backup offline under the exact standard's requirements.
4. Verify a receiving address through the supported trusted device display; send a trivial test amount. Hide identifiers not needed for teaching.
5. Use the supported backup-check process or compatible spare-device recovery. Validate the backup before any reset. A funded primary device is never wiped as a first test.
6. Where the reviewed procedure includes reset/restore, use only the validated test setup and current vendor instructions. Show the restored intended wallet and test funds, with secrets absent from footage.
7. Verify a small outbound transaction and fee through the trusted process. No universal fee or dust threshold.
8. Record recovery success, remaining limitations, and next review. Explain that multisig/configuration/passphrase setups need their own complete proof.

### Readback and finish

A successful small-value recovery of the intended wallet is demonstrated under the exact reviewed procedure. The production export contains no usable key material or sensitive recovery metadata. Without actual hardware proof, this demonstration remains unfilmed and unapproved.
