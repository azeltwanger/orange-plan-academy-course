# WALKTHROUGH 8.5 — document your custody map in Orange Plan (screen share)

**One session, 6 steps (~15 min capture)**

**Before recording:**
□ Custody level from 8.1 in mind · know if the dead-man switch will need cloud sync
□ ⚠ Tier is keyed to ESTATE NET WORTH, not custody choice: Foundation <$500k · Substantial $500k-$2M · HNW $2M+ — the 3 Hardware items only exist at Substantial+
□ ⚠ Local Only mode replaces the switch panel with "Automatic check-in emails require cloud sync" — flip to Cloud at Settings → Data & Privacy now if arming next module
□ Zero secrets on screen — the checklist never asks for any; the ONLY free-text moment is the backup passphrase in step 3

---

**Open:** "This walkthrough turns your custody decisions into an on-screen map: checklist honest, tier confirmed, top single point of failure named, and an encrypted backup of the plan itself."

## □ 1 · Orient on Protect
**Protect (primary nav)**
- top strip: **Estate readiness → {n} of 5 essentials** · 5 segments: Dead man's switch · Heir letter · Protection tier · Checklist · Beneficiaries
- below: **"Next: {action} · start →"** — the app naming the next single fix
- **Needs attention** queue = the fix-one-thing method, one row per essential
- ⚠ two "checklist" strings: readiness bar says **Checklist** · queue row says **Security checklist** — both real

## □ 2 · Walk the checklist as the map
**Needs attention → Security checklist → Open checklist**
- panel: "{n} of {n} for your tier · Substantial ($500K–$2M) · Items name outcomes; any custody model can satisfy them"
- 4 groups (17 items at Substantial): **Hardware** (3, Substantial+ only) · **Distribution** (4) · **Legal** (6) · **Access after death** (4)
- each item has a **How** toggle · checked = struck through
- ⚠ "the top unchecked item is this week's fix, not the whole list"
- honesty beats, verbatim from app: *"Full recovery process tested end-to-end"* / *"Backup seed verified readable"* — check ONLY if the wipe-and-restore happened. "Checked-but-fabricated means the plan believes something untrue."
- SPOF beats: *"Storage locations documented. Hints only"* / *"No single point of failure can destroy access"*
- ⚠ no free-text fields anywhere — checkboxes + How toggles. Never write secrets in the app.

## □ 3 · Back up the plan itself
**Settings → Data & Privacy → Data & backups → Backup & Restore → Export Plan**
- copy: "Export your entire plan as an AES-encrypted restore backup file protected by a passphrase"
- ⚠ opens a PLAINTEXT browser prompt — type off-camera or use a visible throwaway · say: "backup passphrase, NOT a wallet passphrase — two objects, two jobs"
- toast: **Plan exported** · sibling Data Privacy panel shows Cloud / Local Only
- ⚠ click target is the ROW "Data & backups" — "Backup & Restore" is the panel heading after it expands; no top-level tab exists
- "the rest of the module protected the coins. This button protects the map."

## □ 4 · Save the Family Custody Map (course toolkit PDF)
**Materials → 07 Family Custody Map** — print or fill as PDF, store with the will + Heir Letter
- 5 blocks, fill as you talk: **BITCOIN** (one row per instance, provider named) · **WHERE THE BACKUPS ARE** (location ONLY — "steel backup: safe deposit box, First National" never the words) · **ACCOUNTS** (beneficiary forms current) · **INSURANCE & OTHER** · **DOCUMENTS** (original + who has copies)
- ⚠ "this map never contains a secret. It says WHERE things are, never HOW to open them." footer: "never the words, PIN, or passphrase"
- companion framing: letter = who to call in what order · map = what exists and where · both findable by the executor
- set footer review date: "Review yearly. Module 9."

## □ 5 · Record your decisions (off-app)
- custody level chosen (your call, ≠ the app's estate-size tier)
- top SPOF + the one fix this week
- annual custody review on the calendar, recurring
- optional: **Protection tier → Mark as reviewed** · **Protect header → Download estate summary** (PDF)

## □ 6 · The "Draft with AI" button you'll scroll past
- passing the Heir letter section: "there's an assistant for the heir letter. That's next module." Walk past it.
