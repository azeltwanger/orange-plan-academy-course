# Filming aids

**[All teaching and walkthrough scripts in one file](../ALL-FILMING-SCRIPTS.md)** is the main recording manuscript. [Start filming](../START-FILMING.md) explains the separate teaching and walkthrough sessions.

These focused views support recording and editing:

| File | Use it to |
|---|---|
| [Recording order](DICTATION-ORDER.md) | Follow the lesson sequence and open individual teaching teleprompters. |
| [Teaching overlays](TEACHING-OVERLAYS.md) | Match on-screen text to exact spoken cues. |
| [Walkthrough scripts](WALKTHROUGH-SCRIPTS.md) | Record app/device takes with narration, screen actions, overlays, and clean speech links. |
| [Pairing map](FILM-ORDER.md) | Place the relevant walkthrough chapters beside each teaching lesson. |
| [Capture dependencies](WALKTHROUGH-CAPTURE-DEPENDENCIES.md) | Check each actual redesigned flow or device procedure before accepting footage. |
| [Course step map](COURSE-STEP-MAP.md) | Trace a lesson's task to its slide sources and walkthrough. |
| [Member completion checks](MODULE-CHECKPOINTS.md) | See the decision or action each lesson finishes. |
| [Recording status](PRODUCTION-CHECKLIST.md) | See manuscript status and applicable capture/review subjects. |
| [Manuscript lengths](COURSE-METRICS.md) | Compare written speech counts and estimated recording time. |

Edit content in the canonical [scripts](../scripts/) and regenerate these views. Individual speech-only files remain in [teleprompter](../teleprompter/).
