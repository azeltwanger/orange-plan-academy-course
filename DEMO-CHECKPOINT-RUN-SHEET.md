# Orange Plan Academy — demo checkpoint run sheet

**Purpose:** enter the continuous household once, capture every calculated output from the current app, and stop scripts, slides, and walkthroughs from inventing their own results.

**Input authority:** `DEMO-HOUSEHOLD.md`  
**Output authority:** the dated checkpoint receipt produced by this run  
**Security:** fictional data only; never use a real client export or any Bitcoin secret

## Current product limitation

Orange Plan can create an encrypted export, but in-app plan restore is temporarily unavailable. These checkpoints are therefore **versioned receipts**, not importable course fixtures today.

Do not delete or overwrite the working demo account because an encrypted export exists. If restore ships later, verify the process before converting receipts into restore fixtures.
