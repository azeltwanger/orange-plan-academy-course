# 4.1 · Drawdown × allocation = your hit

**Paste `00-STYLE.md` first, then this.**

## What it has to make obvious
That the same crash is a different event at different allocations.

## The visual
Four vertical bars, one per allocation level, each showing the portfolio hit from the same 75% Bitcoin drawdown. Height of the shaded loss grows across the four.

## Labels and data
10% → 7.5% · 25% → 19% · 50% → 37.5% · 75% → 56%

## Motion
One shared 'Bitcoin falls 75%' event fires, then all four bars lose their shaded portion at once so the difference is instant.
